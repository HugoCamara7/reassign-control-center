# Assets

Coloca aqui el logo institucional con uno de estos nombres:

- `forus.png` (recomendado, fondo transparente, ~300x100 px)
- `forus.svg`
- `logo.png`

`ui/theme.logo_data_uri()` lo incrusta como data URI en la barra lateral.
Si no hay ningun archivo, se muestra el texto "FORUS / CONSUMER FANATIC"
como respaldo, sin romper el diseno.
